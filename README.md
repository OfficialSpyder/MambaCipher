# MambaCipher 🔒

A custom proprietary encryption, encoding, and obfuscation library designed for secure tokenization, configuration hiding, and signature verification. Created by <B>Sukhpal Kherera</B>.

---

## Features
- **Digit Substitution:** Maps numbers (0-9) to secure special symbols (`!`, `@`, `#`, etc.).
- **Positional Tagging:** Converts lowercase and uppercase alphabets into indexed position tags (`<pos>` / `[pos]`).
- **Interactive CLI:** Built-in user input mode for direct terminal usage.

---
